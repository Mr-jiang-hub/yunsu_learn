## 1. 产品概述

### 1.1 背景

学员的学习行为目前高度碎片化：看视频、刷题、面试分散在不同平台，学完无法验证，机构也无法掌握真实的学习效果。云枢智学把三者收进同一个闭环，并把结果沉淀为可追踪的数据。

### 1.2 产品定位

面向互联网学员的**技能学习与自测平台**：用「学习路线 → 阶段刷题 → AI 面试」的闭环，把"看视频"这种弱效果行为，转化为可量化、可追踪的技能掌握度。

### 1.3 业务目标

1. 让学员有清晰路径，不纠结"学什么、学到哪"
2. 让学习效果可验证：完成度、掌握度、面试维度分三组数据
3. 让机构用系统化内容 + AI 替代部分人工服务，降低运营成本

### 1.4 非目标（本期范围外）

在线支付/订单/会员权益、多机构租户、平台自建视频播放、知识点体系与按知识点组卷、随机组卷/模拟考试、B 站链接自动失效检测、学员个体追踪名单、自定义报表、微信/第三方登录。

### 1.5 成功衡量

建议关注：主路线加入率、阶段完成率、练习参与率、面试完成率、面试维度分随次数的提升幅度。

## 3. 核心业务流程

### 3.1 学员主流程

```
注册/登录
  → 未加入路线：引导选择一条主学习路线
  → 首页（当前路线 + 进度 + 继续学习 + 工具入口）
  → 进入阶段：看课程（跳 B 站）→ 标记完成
  → 阶段刷题：逐题作答 → 即时判分 + 解析 → 出正确率
  → 错题进入错题本 → 可一键重练
  → AI 面试：选学科与难度 → 语音问答（按当前阶段动态出题） → 出维度报告
  → 按报告薄弱维度回到路线补课 / 重刷错题
```

### 3.2 运营主流程

```
建学科 → 建学习路线 → 建阶段 → 录课程（B 站链接）
→ 录/导入题目并挂到阶段 → 配置学科能力维度与面试难度
→ 学员学习 → 看板观察完成率/正确率/面试维度分 → 调整内容
```

## 4. 信息架构与内容模型

```
学科（= 学习方向）
└── 学习路线（一个学科对应一条）
    └── 阶段（有序）
        ├── 课程（一门 = 一个 B 站视频链接）
        └── 题目（判断 / 单选 / 多选 / 简答）
```

**约束**

- 无"知识点"层
- 一道题只属于一个阶段，不支持复用
- 一门课程只对应一个视频链接，无课时/分 P 层
- 学科与路线一一对应

## 5. C 端功能需求

### 5.1 注册与登录

| 项 | 规则 |
|---|---|
| 注册 | 手机号 + 短信验证码，**必须设置密码** |
| 登录 | 手机号 + 验证码 / 手机号 + 密码，二选一 |
| 找回密码 | 手机号 + 验证码重置 |
| 验证码 | 同一手机号 60 秒内限发 1 次，有效期 5 分钟，单号单日上限 10 次 |
| 密码 | 8–20 位，需包含字母与数字 |
| 密码错误 | 连续 5 次错误后，需改用验证码登录或重置密码 |
| 注册后 | 首次进入引导"选择主学习路线" |

**异常**：手机号已注册（引导登录/找回）、验证码错误或过期、短信发送失败（提示稍后重试）。

### 5.2 首页

**组成**

1. 当前主路线卡片：路线名、总进度、当前阶段
2. 继续学习：当前阶段下一门未完成课程，一键跳转
3. 工具入口：去刷题 / AI 面试 / 错题本 / 面试记录
4. 未加入路线时：替换为"选择学习路线"入口
5. 最近动态摘要：阶段掌握度、最近一次练习、最近一次 AI 面试

**规则**：无推荐位、无跨路线推荐、无连续天数等激励模块（本期不做）；最近动态仅做摘要展示，不扩展为消息中心。

### 5.3 学习路线

| 项 | 规则 |
|---|---|
| 加入主路线 | 同一时间只能有一条；已加入可更换 |
| 更换路线 | 原路线进度保留，换回可继续 |
| 阶段解锁 | 不锁，全部可进 |
| 顺序引导 | 展示"建议按顺序学习"，高亮当前阶段 |
| 阶段状态 | 未开始 / 进行中 / 已完成（课程全部完成） |
| 路线进度 | 已完成课程数 ÷ 路线总课程数 |

### 5.4 课程学习与进度

| 项 | 规则 |
|---|---|
| 课程内容 | 标题、简介、B 站视频链接、时长（选填）、封面（选填，留空用占位图） |
| 学习动作 | 点击 → 记录"开始学习" → 新窗口/跳转 B 站 |
| 完成判定 | 从 B 站返回后弹出轻提示"这节课看完了吗？"，确认即完成；课程旁也可手动打勾 |
| 阶段完成 | 阶段内课程全部完成 |
| 完成度与掌握度 | 两个独立指标，不互相影响 |

**异常**：链接失效时页面提示"视频可能已失效"，不阻断流程（不做自动检测）。

### 5.5 刷题

**入口**：阶段页 → 开始刷题；范围为该阶段全部题目。

**流程**

1. 创建一次练习（类型：阶段练习）
2. 一题一屏，逐题作答
3. 提交当前题 → 即时判分 → 展示正确答案与解析 → 下一题
4. 全部完成 → 结果页（正确率、对错清单、用时）

**判分规则**

| 题型 | 判分 |
|---|---|
| 判断题 | 选项一致即正确 |
| 单选题 | 选项一致即正确 |
| 多选题 | **全对才得分**，漏选/错选均判错 |
| 简答题 | 大模型按"评分点"判分，得分率 ≥ 60% 视为正确；返回逐点命中情况 |

**简答降级**：模型超时或调用失败 → 展示参考答案，学员自评"答对/答错"，并记录降级标记。

**掌握度**：取最近一次阶段练习正确率；题量 < 10 标注"样本较少"。

**中途退出**：保留进度，**7 天内可续答**；超时自动作废，未完成的练习不计入掌握度。

### 5.6 错题本

| 项 | 规则 |
|---|---|
| 进入 | 任意题型答错（客观题判错；简答得分率 < 60%） |
| 移出 | 后续任意一次作答正确即自动移出 |
| 展示 | 按学科/阶段分组，展示题干、我的答案、正确答案、解析 |
| 重练 | 支持将错题组成一次练习，类型记为"错题重练"；可先按学科/阶段筛选，默认全部错题 |
| 重练影响 | 不计入阶段完成度与掌握度；答对同样移出错题本 |

**说明**：不重做该阶段，错题不会被移出——这是规则的固有结果，需在页面文案中说明。

### 5.7 AI 语音面试

**入口**：首页工具入口 / 面试记录页 → 选择学科与面试难度（简单 / 中等 / 困难）；入口展示今日剩余面试次数。

**前置条件**：该学科已配置能力维度、至少一个启用中的难度档位，存在可用学习阶段，且学员今日剩余面试次数大于 0；否则入口置灰并提示。

**流程**

1. 校验学员今日剩余面试次数；为 0 则不可创建，提示次日 00:00 恢复
2. 选择学科与难度 → 创建面试会话（状态：创建中；创建即计 1 次）
3. 创建会话时按学员主路线确定当前阶段并快照；若主路线不属于所选学科，取该学科学习路线的起始阶段
4. 第 1 题：大模型基于快照阶段的课程内容生成开场题；生成成功后会话转为"进行中"
5. 学员语音作答，系统自动转写为文字；转写结果可编辑后提交
6. 大模型结合阶段课程内容与上一轮回答生成追问，共 3 轮
7. 共 4 轮问答（开场 1 + 追问 3）后自动结束
8. 生成报告

**规则**

| 项 | 规则 |
|---|---|
| 形态 | 语音多轮对话，自动转文字；不支持语音时降级为文字作答 |
| 出题 | 大模型基于阶段课程内容与上一轮回答实时生成，不使用固定题库 |
| 难度 | 简单 / 中等 / 困难，控制提问深度；档位由后台配置 |
| 阶段 | 创建会话时确定并快照，会话期间不随主路线切换而变化 |
| 轮次 | 固定 4 轮 |
| 每日次数 | 每学员每天最多 3 次，按自然日 Asia/Shanghai 00:00 重置；不按学科/难度拆分；未使用不累积 |
| 次数扣减 | 创建会话即计 1 次；正常完成、提前结束、未完成、已过期均计入 |
| 故障返还 | 系统/AI 故障导致开场题未生成、会话未进入可作答状态的，会话作废并返还本次次数；作废会话不计入面试记录与统计 |
| 续答 | 恢复已有会话不重复计数，也不占用当日额度 |
| 并发 | 同一学员并发创建时不得突破每日上限 |
| 音频 | 不保存音频，仅保存转写文本 |
| 提前结束 | 允许；报告标注"未完成"，不计入正常成绩 |
| 中断续答 | 自动保存，24 小时内可回到断点继续 |
| 超时 | 超过 24 小时未完成 → 状态"已过期"，不生成正式报告，保留对话记录 |
| 重复面试 | 在每日次数上限内允许；历史全部保留（作废会话除外） |
| 评分维度 | 由该学科的"能力维度"配置决定 |

### 5.8 面试记录与报告

**记录列表**：按时间倒序，展示学科、难度、阶段、时间、轮次、状态、总评；作废会话不展示。

**报告内容**

- 总评（文字 + 总分）
- 各能力维度得分（雷达/条形）
- 薄弱维度提示
- 改进建议（2–3 条文字建议）
- 面试状态（正常完成 / 未完成）

**历史对比**：选择同一学科的两场面试，对比各维度分变化。

### 5.9 学习记录

- 课程完成记录：课程、完成时间、所属阶段
- 练习记录：类型（阶段练习 / 错题重练）、阶段、正确率、时间
- 阶段掌握度：最近一次正确率 + 最近几次趋势
- 记录长期保留；账号注销后脱敏保留

### 5.10 个人中心

- 修改昵称、头像
- 修改密码（需原密码或验证码，二选一）
- 手机号换绑（原号 + 新号双重验证）
- 注销账号（验证码确认；注销后清除身份信息、匿名行为记录保留、手机号释放）
- 注销双入口职责：个人中心自助注销由学员本人发起；运营后台注销用于协助学员或违规处置，需二次确认并写操作日志。两者执行同一注销结果

## 6. B 端功能需求

### 6.1 登录与权限

- 账号密码登录，无自助注册；由超管创建
- 登录后按角色展示模块菜单
- 操作日志记录登录与关键写操作

### 6.2 学科管理

字段：名称、简介、封面、排序、状态（启用/停用）。停用后 C 端不可见，已有学员数据保留。

### 6.3 课程库

- 展示全部课程，支持按学科/阶段筛选
- 新建/编辑：标题、B 站链接、简介、时长（选填）、封面（选填）、所属阶段、排序
- 不支持课程跨阶段复用

### 6.4 刷题题库

- 列表、筛选（学科/阶段/题型）、新建、编辑、停用
- 字段：题型、题干、选项、正确答案、解析、所属阶段
- 简答题额外字段：参考答案、评分点
- **批量导入**：Excel 模板下载 → 上传 → 校验（题型、选项数量、答案完整性、简答评分点）→ 返回成功/失败行及原因 → 支持重复题判定
- 导入失败**整批回滚**，不写入任何数据
- 题目只做停用（软删除），不允许硬删除；已有作答记录保留

### 6.5 面试设置

- 难度档位：简单 / 中等 / 困难，维护启用状态、难度描述与考察重点；停用后 C 端不可选。难度为全局三档，不与学科绑定（Q29 已确认）
- 能力维度：在学科下配置（名称、排序），供面试出题与报告评分使用
- 不维护固定题目；题目由大模型基于学员当前阶段课程内容与上一轮回答实时生成
- 配置校验：学科至少具备能力维度、一个启用中的难度档位与可用学习阶段，才能发起面试

### 6.6 学习路线管理

- 路线：名称、所属学科、简介、状态
- 阶段：名称、排序、简介；可增删改、调整顺序
- 阶段下挂课程与题目：从课程库/题库中选取，或直接新建

### 6.7 学员管理

| 操作 | 说明 |
|---|---|
| 查询 | 手机号、昵称、加入路线、注册时间、状态 |
| 重置密码 | 生成临时密码，学员首次登录后强制修改 |
| 修改主路线 | 运营代为变更，原进度保留 |
| 禁用/启用 | 禁用后不能登录，数据保留 |
| 注销 | 运营侧注销入口，用于协助学员或违规处置；二次确认并写操作日志，身份脱敏、匿名行为记录保留、手机号释放 |

### 6.8 系统用户与角色

- 系统用户：新增、编辑、禁用、重置密码
- 不支持删除系统用户，只允许停用；停用后不能登录，历史操作日志保留
- 角色：仅三类预置角色，可编辑每个角色可访问的模块；**不支持新建角色**

### 6.9 操作日志

记录：操作人、角色、模块、操作类型、对象、时间、IP。支持按人/时间/模块筛选。只读，不提供日志导出。

### 6.10 数据看板

| 分组 | 指标 |
|---|---|
| 规模 | 学员总数、新增学员、活跃学员（当天任意行为） |
| 学习 | 课程完成数、阶段完成数、路线进度分布 |
| 练习 | 练习次数、平均正确率、题型正确率分布 |
| 面试 | 面试场次、完成率、各学科维度平均分 |
| 内容效果 | 各路线完成率、各阶段完成率与正确率 |
| 趋势 | 日/周/月趋势（支持今日 / 近 7 天 / 近 30 天） |

不做个体追踪名单、不做导出、不做自定义报表。

## 7. 关键规则与算法

### 7.1 判分

- 判断/单选：完全一致
- 多选：全对才得分，漏选/错选均判错
- 简答：按评分点由大模型判分，得分率 ≥ 60% 判对；失败降级自评

### 7.2 掌握度

`最近一次阶段练习的正确率`；题量 < 10 展示"样本较少"，不参与加权。

### 7.3 完成度

`阶段内已完成课程数 ÷ 课程总数`；错题重练不计入。

### 7.4 错题本

答错进入 → 任意一次答对移出 → 支持重练 → 重练不计入完成度与掌握度。

### 7.5 面试评分

- 维度来自"学科能力维度"
- 每轮回答由大模型结合阶段内容、面试难度与能力维度打分，结束后汇总为维度分（0–100）与总分
- 未完成面试：报告标注状态，分数仅供参考

### 7.6 注销

清除手机号、昵称、头像等身份信息；以匿名 ID 保留学习/练习/面试记录；手机号释放可重新注册。

## 9. 状态机

**学员账号**：正常 → 禁用（可恢复）；正常 → 已注销（不可恢复）

**面试会话**

```
创建中 ──开场题生成成功──→ 进行中
   └──系统/AI 故障──→ 已作废（不计次数，不生成报告，不进入记录/统计）

进行中 ──完成 4 轮──→ 正常完成
   │
   ├──学员点"提前结束"──→ 未完成（出报告，标注）
   └──超过 24 小时──→ 已过期（不出正式报告）
```

**练习**

```
进行中 ──全部作答──→ 已完成
   └──中途退出──→ 保留进度，7 天内可续答；超时作废
```

**题目导入**：处理中 → 全部成功 / 全部失败

## 10. 异常与边界

| 场景 | 处理 |
|---|---|
| 视频链接失效 | 提示"视频可能已失效"，流程不阻断 |
| 简答判分超时/失败 | 降级为参考答案 + 学员自评 |
| 面试中途断线 | 24 小时内可续答 |
| 今日面试次数已用完 | 入口置灰/创建被拒绝，提示次日 00:00 恢复 |
| 开场题生成失败 | 会话作废并返还本次次数，提示稍后重试；不进入面试记录与统计 |
| 创建中长时间未完成 | 会话作废并返还本次次数，提示重试 |
| 同一学员并发创建面试 | 原子占用次数，最多创建至每日上限，超出请求被拒绝 |
| 面试维度/难度未配置，或学科无可用阶段 | 该学科面试入口置灰并提示 |
| 学员未加入路线 | 首页引导选择路线，工具入口仍可用 |
| 运营删除已被使用的题目 | 只允许停用（软删除），历史作答保留 |
| 注销学员的历史数据 | 保留脱敏，计入历史统计 |
| 批量导入含错误行 | 整批回滚，返回错误行与原因 |

## 11. 非功能需求

- **安全**：密码加密存储；验证码限频；B 端连续 5 次登录失败锁定 15 分钟；敏感操作记日志
- **合规**：手机号等个人信息最小化采集；提供注销能力；注销后脱敏
- **性能**：C 端页面首屏与题目提交响应；简答判分展示"评分中"状态
- **可用性**：大模型不可用时降级，不阻断学习与刷题

| 9 | 优先级划分 | 维持第 12 章 |
| 10 | 错题重练范围 | 可按学科/阶段筛选，默认全部错题 |
| 11 | 验证码与密码规则 | 60 秒限发、5 分钟有效、单号单日 10 次；密码 8–20 位含字母数字 |
| 12 | 是否允许新建角色 | 不允许，仅三类预置角色 + 模块权限可编辑 |
| 13 | 题目硬删除 | 不允许，仅停用（软删除） |
| 14 | 学习记录保留 | 长期保留；注销后脱敏保留 |
| 15 | 面试阶段确定 | 优先主路线当前阶段；主路线不属于所选学科时，取该学科路线起始阶段；创建会话时快照 |
| 16 | 面试音频留存 | 不保存音频，仅保存转写文本 |
| 17 | 后台系统用户删除 | 不允许删除，只允许停用 |
| 18 | 操作日志导出 | 不提供导出 |
| 19 | 首页最近动态 | 保留，仅做摘要展示，不扩展为消息中心 |
| 20 | 注销双入口 | 自助注销与后台注销并存；自助由学员发起，后台用于协助或处置，职责分开、结果一致 |
| 21 | AI 面试每日次数 | 每学员每天最多 3 次，按自然日 Asia/Shanghai 00:00 重置，不按学科/难度拆分，未使用不累积；创建会话即计 1 次，正常完成/提前结束/未完成/已过期均计入；系统或 AI 故障导致开场题未生成、会话未进入可作答状态的，会话作废并返还本次次数；续答不重复计数 |
| 22 | 面试难度归属 | 全局三档（简单/中等/困难），不与学科绑定；学科只要存在启用档位即可发起（已确认 Q29） |
| 23 | 面试创建中与进行中时限 | 创建中最多 5 分钟；开场成功后转为进行中，进行中最多 24 小时；创建中超时作废并返还次数，进行中超时置已过期且不返还 |
| 24 | 面试轮次语义 | 数据库记录“已完成作答轮次”0–4；接口 `currentRound` 表示“当前待答轮次”1–4；正常完成后固定为 4 |
| 25 | 练习提交条件 | 必须全部题目已作答才可提交；未答完返回业务错误，不生成结果 |
| 26 | 面试报告生成 | 第 4 轮完成或提前结束后异步生成；报告未就绪时接口返回“生成中”，前端短轮询；过期/作废不生成正式报告 |
| 27 | 短信网关失败 | 当日发送次数不返还，验证码置作废；防止以故障为由刷网关（默认值，触发条件：网关失败率连续 7 天 > 1% 时复核） |
| 28 | 签名 URL 时效 | OSS 私有 Bucket 的图片/文件访问签名 URL 有效期 15 分钟 |
| 29 | 操作日志保留 | 在线保留 1 年，超期归档；不提供导出 |
| 30 | 首页/看板缓存 | 首页与看板聚合结果缓存 60 秒，响应带 `dataAsOf` 与延迟提示 |
| 31 | 批量导入上限 | 单文件 ≤ 5 MB、≤ 1000 行；任一行校验失败整批回滚，返回行号与原因 |
| 32 | 手机号存储 | 应用层 AES-GCM 加密 + HMAC-SHA256 盲索引；唯一索引落盲索引，注销时释放手机号（已确认 Q18） |
| 33 | 最近活跃 | 不建活动表，由最近登录、课程开始、练习创建、面试创建四类时间派生（默认值） |
| 34 | 错题重练跨阶段 | `practice.stage_id` 允许为空；错题本按题目所属阶段展示（默认值） |
