## 1. 路径与版本

1. 统一前缀 `/api/v1`，版本号写在路径中，不使用 Header 版本。
2. 端侧分段，**C/B 必须用不同前缀，便于分别挂载认证链与权限拦截器**：
   - C 端学员：`/api/v1/c/**`
   - B 端管理：`/api/v1/admin/**`
   - 回调与内部：`/api/v1/internal/**`（不对公网暴露，网关层拒绝外部访问）
3. 资源用复数名词，嵌套层级不超过两层：
   - ✅ `GET /api/v1/c/stages/{stageId}/courses`
   - ❌ `GET /api/v1/c/getStageCourseList`
4. 动作无法用资源表达时才用子路径（子路径是动作名，不是动词化资源）：
   - `POST /api/v1/c/practices/{id}/submit`
   - `POST /api/v1/c/interview-sessions/{id}/finish`
   - `POST /api/v1/c/interview-sessions/{id}/answers`（提交一轮语音/文字作答）
5. 路径一律小写 kebab-case，禁止下划线与大写。
6. 路径中不使用动词 `do/process/handle`，不使用文件扩展名。

## 2. HTTP 方法与语义

| 方法 | 语义 | 幂等 | 本项目约束 |
|---|---|---|---|
| GET | 查询，无副作用 | 是 | 不得用于写操作，不得用于统计刷新 |
| POST | 创建资源 / 触发动作 | 否 | 必须有幂等策略（第 9 章） |
| PUT | 全量更新 | 是 | 仅用于确定的整体替换 |
| PATCH | 局部更新 | 是 | **不接受 `status` 字段**（第 10 章） |
| DELETE | 删除 | 是 | 本项目多为"停用"语义，见第 10 章 |

1. 查询一律用 GET；复杂筛选如必须用 POST，需在 OpenAPI 中显式标注"查询接口，无副作用"。
2. 业务状态变更必须走专用动作接口，不允许在通用更新接口里传 `status` 直接改。
3. 修改类接口返回变更后的完整对象，避免前端二次拉取。
4. 批量操作要么提供显式批量接口，要么由前端串行调用，不允许"传数组进单条接口"的隐式批处理。

## 3. 统一响应

1. 所有接口返回统一结构，HTTP 状态码与业务码分离：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "9f8c2a1b7e3d4c50"
}
```

2. 成功：`code = 0`，HTTP 200（创建可 201）。业务失败：**按 Q22 定稿后全项目统一**，当前倾向 HTTP 200 + `code != 0`，禁止两种混用。
3. 系统异常：HTTP 5xx，`code` 用系统级错误码，`message` 不暴露堆栈、SQL、类名。
4. `data` 为 `null` 时保留字段，不省略 key。
5. 列表统一返回：

```json
{ "code": 0, "data": { "list": [], "total": 0, "page": 1, "size": 20 } }
```

6. 禁止直接返回数据库实体：必须有 DTO，且不得包含 `password`、`deleted_at`、内部自增以外的敏感字段。
7. 响应必须带 `traceId`，同时写入响应头 `X-Trace-Id`，便于前端报障定位。

## 4. 错误码

1. 五位数字分段，**一旦分配不可重用、不可改语义**：

| 区间 | 含义 | 示例场景 |
|---|---|---|
| 0 | 成功 | — |
| 10000–19999 | 通用 | 参数校验失败、限流、系统异常 |
| 20000–29999 | 认证与授权 | 未登录、Token 过期、无权限、账号被禁用 |
| 30000–39999 | C 端业务 | 验证码、密码、练习、错题、面试 |
| 40000–49999 | B 端业务 | 内容管理、学员管理、角色、批量导入 |
| 50000–59999 | 外部依赖 | 短信、大模型、ASR/TTS、OSS |

2. **必须单独定义的业务码（不得复用通用码）**：

| 场景 | 说明 |
|---|---|
| 面试次数已用完 | 前端需展示"今日 3 次已用完"并提供次日提示，不能与"参数错误"混用 |
| 面试会话已过期 / 已作废 | 与"无权限"区分，前端要走不同引导 |
| 练习已结束 / 已作废 | 续答场景必须能识别 |
| 简答判分超时 | 前端据此切换"学员自评"降级界面 |
| 验证码发送过于频繁 | 需返回剩余等待秒数 |
| B 端账号锁定 | 需返回解锁时间 |

3. 每个错误码必须在 `docs/api/error-codes.md`（或等价位置）登记：码值、中文提示、触发条件、前端处理建议。
4. `message` 面向用户，中文、可读、可操作；不得出现字段名、异常类名、SQL。
5. 校验失败返回字段级明细：

```json
{ "code": 10001, "message": "参数校验失败",
  "data": { "errors": [{ "field": "phone", "message": "手机号格式不正确" }] } }
```

6. 同一业务失败只用一个码，不为前端展示差异拆码。
7. 降级不是错误：简答判分失败降级、语音识别失败转文字，均返回成功 + 状态标记（第 11 章），不抛业务错误码。

## 5. 命名与字段

1. JSON 字段统一 lowerCamelCase（与库内 snake_case 解耦，由 DTO 转换）。
2. 枚举返回稳定字符串（`IN_PROGRESS` / `FINISHED` / `EXPIRED`），**不返回数字**；数字码只用于存储。
3. 布尔字段用 `is` / `has` 前缀，值为真正的布尔，不用 `0/1`。
4. 时间字段统一 `xxxAt` 后缀，RFC 3339 UTC；禁止 `xxxTime` 与 `xxxAt` 并存。
5. 比率字段带量纲：`correctRate`（0–100，两位小数）而非 `rate`。
6. 分页字段固定 `page`（从 1 开始）、`size`、`total`。
7. 关联对象：`subjectId` 用于标识；`subjectName` 等冗余展示字段须在 OpenAPI 中说明用途（列表页减少请求）。
8. 快照字段明确命名：面试会话返回 `stageId` + `stageName` 时，`stageName` 为**创建时快照**，不随阶段改名变化，需在文档注明。
9. 列表项字段顺序统一：标识 → 业务字段 → 状态 → 时间。

## 6. 参数校验

1. 所有入参在接口层用 Jakarta Validation 强制校验：必填、类型、长度、范围、枚举、格式。
2. 校验规则必须与 PRD 一致，不得放宽：

| 项 | 规则（PRD 依据） |
|---|---|
| 密码 | 8–20 位，含字母与数字（5.1） |
| 验证码 | 6 位数字；60 秒限发 1 次、5 分钟有效、单号单日 10 次（5.1） |
| 注册 | 手机号 + 验证码，必须设置密码（5.1） |
| 密码错误 | 连续 5 次后需改用验证码登录或重置（5.1） |
| 简答判对 | 得分率 ≥ 60%（5.5） |
| 面试难度 | 简单 / 中等 / 困难，必须是启用中的档位（5.7） |
| 面试轮次 | 固定 4 轮（开场 1 + 追问 3）（5.7） |
| 面试每日次数 | 每学员每日最多 3 次，按 `Asia/Shanghai` 自然日（5.7 / 13 章 21 条） |
| 练习续答 | 7 天内可续（5.5） |
| 面试续答 | 24 小时内可续（5.7） |
| B 端登录 | 连续 5 次失败锁定 15 分钟（11） |

3. 禁止信任前端传入的身份与权限：`studentId`、`adminId`、`role` 一律取自登录态，不从 body/query 取。
4. 富文本与长文本（题干、解析、总评、学员答案）必须限长并做 XSS 过滤/转义。
5. URL 类参数（B 站课程链接）校验格式与域名白名单；外部跳转不得由后端重定向，避免开放重定向。
6. 分页与排序参数必须校验上限与白名单（第 7 章）。

## 7. 分页、排序、筛选

1. 列表接口必须分页，`size` 默认 20、上限 100，超限直接返回参数错误。
2. 排序字段必须白名单校验，禁止把前端字段名拼进 `ORDER BY`。
3. 筛选参数命名统一：`subjectId`、`stageId`、`status`、`questionType`、`startDate`、`endDate`。
4. 日期区间一律闭区间或半开区间，必须在文档中写明；时间统一 RFC 3339。
5. 空筛选表示不筛选，不得用空字符串匹配数据库空值。
6. 深分页（页码过大）需评估；数据量大的表改用游标接口并单独定义响应结构。
7. 排序必须保证确定性（服务端追加 `id` 兜底），否则翻页会重复或漏行。

## 8. 认证与授权

1. **C/B 双端隔离**：不同 audience、不同密钥、不同认证链；B 端 Token 调 C 端接口必须拒绝，反之亦然。
2. JWT 有效期：Access 30 分钟、Refresh 7 天（Q27 默认值）；Refresh 哈希落库，支持注销/改密/禁用时撤销。
3. 每次鉴权必须校验账号状态（学员禁用/注销、B 端账号停用 → 立即失效）。因无 Redis，**状态校验直接查库或走短 TTL 本地缓存（≤ 60s）**，不得只依赖 Token 内嵌信息。
4. **越权校验是强制项**：所有涉及 `practice`、`answer`、`wrong-question`、`interview-session`、`interview-report`、`course-progress` 的读写，必须校验资源归属当前登录学员；禁止仅靠 id 不可猜测做防护。
5. B 端按「模块级权限」校验（PRD 2.3）：每个 admin 接口声明所属模块，由统一拦截器校验角色可访问性；不做按钮级、不做数据行级。
6. 权限不足返回 403 + 专属码，不使用 404 掩盖。
7. 敏感操作必须写操作日志（PRD 6.9）：重置学员密码、改主路线、禁用/注销、修改角色权限、批量导入、删除类操作。
8. 密码、验证码、Token 不得出现在 URL 查询串、日志、错误信息中。
9. 登录接口必须做失败计数（落 MySQL 原子计数），并在返回中区分"账号或密码错误"与"账号已锁定"。
10. **Refresh Token 以 HttpOnly Cookie 交付**（2026-11-01 定稿，05 §6 #52，替代 04 早期 JSON body 方案）：C 端 Cookie `ys_c_rt`（`Path=/api/v1/c`）、B 端 `ys_b_rt`（`Path=/api/v1/admin`）；属性 `HttpOnly; SameSite=Lax; Max-Age=604800`，`Secure` 按 profile（dev 关、prod 开）。登录/注册/短信登录成功、刷新轮换成功时 `Set-Cookie` 下发；登出与 `20008/20009` 失败时由**服务端**清除 Cookie（`Max-Age=0`）。刷新/登出接口无请求体。CSRF 依据见 02 §2.6。

## 9. 幂等与限流

1. 以下接口**必须幂等**，重复调用结果一致且不产生重复数据：

| 接口 | 幂等策略 |
|---|---|
| 发送验证码 | 60 秒窗口内重复调用返回同一结果，不重复发送 |
| 标记课程完成 | `(studentId, courseId)` 唯一，重复只更新时间 |
| 创建面试会话 | 客户端幂等键 + 每日配额原子占用，重复请求不得扣两次次数 |
| 提交某轮面试作答 | `(sessionId, round)` 唯一，重复提交覆盖而非追加 |
| 提交练习答案 | `(practiceId, questionId)` 唯一 |
| 结束练习 / 结束面试 | 条件更新状态，已结束则直接返回当前结果 |
| 题库批量导入 | 同一批次号重复提交返回首次结果 |

2. 创建类 POST 支持 `Idempotency-Key` 请求头；服务端记录键与结果，有效期 ≥ 24 小时（落库，因无 Redis）。
3. 限流规则必须与 PRD 一致，且**在数据库层原子判断**：
   - 验证码：60 秒 1 次、5 分钟有效、单号单日 10 次
   - B 端登录：连续 5 次失败锁定 15 分钟
   - 面试：每学员每日 3 次（第 10 章）
4. 限流响应返回 429 + 专属码 + 剩余等待秒数，便于前端倒计时。
5. 禁止用内存计数承载安全边界（P0 无 Redis，重启即失效且多实例不一致）。

## 10. 状态流转

1. 资源状态只能通过专用动作接口变更，通用 `PATCH` 不接受 `status` 字段。
2. **练习**（PRD 8 章：进行中 / 已完成 / 已作废）：

| 动作 | 接口 | 允许前置状态 |
|---|---|---|
| 创建阶段练习 | `POST /c/stages/{stageId}/practices` | — |
| 创建错题重练 | `POST /c/practices/wrong-questions` | — |
| 提交单题作答 | `POST /c/practices/{id}/answers` | 进行中 |
| 交卷 | `POST /c/practices/{id}/submit` | 进行中 |
| 续答（7 天内） | `GET /c/practices/{id}` + 续答态 | 进行中且未过期 |
| 作废（超时） | 系统任务，无对外接口 | 进行中且超 7 天 |

3. **面试会话**（PRD 8 章：创建中 / 进行中 / 正常完成 / 未完成 / 已过期 / 已作废）：

| 动作 | 接口 | 允许前置状态 |
|---|---|---|
| 查询今日剩余次数 | `GET /c/interview-quota` | — |
| 创建会话（计 1 次） | `POST /c/interview-sessions` | 剩余次数 > 0 且学科配置完备 |
| 提交一轮作答（语音/文字） | `POST /c/interview-sessions/{id}/answers` | 进行中 |
| 提前结束 | `POST /c/interview-sessions/{id}/finish` | 进行中 |
| 查询报告 | `GET /c/interview-sessions/{id}/report` | 正常完成 / 未完成 |
| 续答（24 小时内） | `GET /c/interview-sessions/{id}` + 续答态 | 进行中且未过期 |
| 作废并返还次数 | 系统任务，无对外接口 | 创建中且开场题未生成 |

4. **配额与状态的联动规则（不得在接口层随意实现）**：
   - 创建会话即扣 1 次，扣减与创建必须在同一事务；
   - 已计入的次数在 正常完成 / 未完成 / 已过期 时**不返还**；
   - 仅"系统或 AI 故障导致开场题未生成、会话未进入可作答状态"时作废并返还，返还必须幂等；
   - 续答不重复计数。
5. 非法状态流转返回业务错误码（如"该练习已结束"），不返回 5xx。
6. 过期判定（练习 7 天、面试 24 小时、每日次数跨天）全部以**服务端时间**为准；前端倒计时仅作展示。
7. 每日次数跨天重置按 `Asia/Shanghai` 自然日 00:00，接口返回 `quotaDate`（上海日期）与 `remaining`，避免前端自行推算时区。

## 11. AI 能力相关接口

### 11.1 大模型（判分、出题、报告）

1. 调用必须设置超时（建议 10 秒）与重试（1 次），并使用 Resilience4j 熔断；不得阻塞主流程。
2. 简答判分失败降级（PRD 5.5）：返回 `scored: false` + 参考答案，前端切换学员自评；接口本身返回成功。
3. 面试追问生成失败：允许重试 1 次，仍失败则结束会话并出"未完成"报告，不丢弃已有对话。
4. 响应必须区分结果与状态，禁止用分数 0 表示失败：

```json
{ "scored": true, "degraded": false, "score": 80, "hitPoints": [...] }
```

5. 调用必须记录：耗时、Token 用量、模型名、是否降级，用于成本与质量分析。
6. "评分中"交互按 Q21 定稿：若同步等待，超时阈值必须小于网关超时；若改异步，需提供结果查询接口并保持响应结构不变。

### 11.2 语音（ASR / TTS，PRD 5.7 语音面试）

1. **音频不落盘**（02 §5.1）：前端上传音频流 → 后端代理 ASR → 返回转写文本，音频只在内存/流转发，不写 OSS、不写磁盘、不入库。
2. 语音作答接口独立于文字作答，避免把大体积二进制塞进普通 JSON 接口：
   - `POST /api/v1/c/interview-sessions/{id}/answers/audio`（`multipart/form-data`，字段：`audio`、`round`）
   - 返回：转写文本 `transcript` + 该轮是否可用 + `asrDegraded` 标记
3. 音频约束：格式白名单（如 `webm/opus`、`wav`）、单轮时长上限（如 60 秒）、体积上限（如 2 MB），超限返回专属码。
4. **ASR 失败必须降级为文字输入**：返回 `asrDegraded: true` + 空转写，前端提示"语音识别失败，请改用文字作答"，不得让会话卡死。
5. TTS 播报（题目、追问、报告摘要）：返回音频流或短时效签名地址，**不得生成持久文件**；TTS 失败时前端回退为纯文本展示，不阻断流程。
6. 语音接口的超时与重试独立于大模型（ASR 建议 ≤ 15 秒），并分别统计耗时与失败率。
7. 同一轮重复上传语音：以 `(sessionId, round)` 为准覆盖，不追加新消息、不重复触发追问。

## 12. 文件上传与批量导入

1. 上传接口限制类型与大小（头像/封面图片、题库 `.xlsx`），超限返回专属码；服务端二次校验 MIME 与真实后缀。
2. 文件存储使用私有 Bucket：**数据库存 key，不存完整 URL**；返回给前端的是短时效签名地址。存储实现经协议无关的 `ObjectStorage` 端口隔离：开发 `S3StorageAdapter` + MinIO，生产 `OssStorageAdapter` + 阿里云 OSS；`LocalStorageAdapter` 仅用于单元测试，不作为开发实现。接口契约保持一致。
3. 头像/封面上传返回 `{ key, url, expireAt }`，前端不得缓存过期 URL。
4. **题库批量导入**（PRD 6.4）流程固定为：模板下载 → 上传 → 校验 → 结果。
   - `GET /admin/questions/import-template`（模板下载）
   - `POST /admin/questions/import`（上传，`multipart/form-data`）
   - `GET /admin/questions/import/{taskId}`（查询结果：成功行数、失败行号与原因）
5. 导入为**整批事务**：任一行失败则整批回滚，不写入任何数据；返回失败明细供用户修正。
6. 导入不得同步阻塞请求线程（02 §2.7：`@Async` + 数据库任务状态），接口立即返回 `taskId`，前端轮询任务状态；任务中断（应用重启）需标记失败并允许重试。
7. 重复题判定规则必须在接口文档中写明（按题干 + 阶段 + 题型）。

## 13. 日志与可观测

1. 每个请求生成 `traceId`，写入响应体与 `X-Trace-Id` 响应头，跨内部调用传递。
2. 访问日志记录：路径、方法、状态码、耗时、登录主体 id；**不记录**手机号明文、密码、验证码、Token、音频内容、完整学员答案。
3. 慢接口（> 1s）记录入参摘要与耗时分布，用于定位。
4. 外部依赖（短信、Qwen、ASR/TTS、OSS）的失败必须单独计数并可告警，错误码与业务错误码分离（5xxxx 段）。
5. 关键业务动作（配额扣减/返还、判分降级、导入回滚）必须有结构化日志，字段固定，便于统计。

## 14. 兼容性与变更

1. 接口一旦被前端使用，只能**向后兼容**演进：新增字段可空、新增枚举值需前后端同步评估，不得删除字段或改语义。
2. 破坏性变更必须新开 `/api/v2` 或新增接口，旧接口保留至少一个迭代并标注废弃时间。
3. 接口变更必须同步：OpenAPI 文档、PRD 相关章节（涉及业务规则时）、前端契约类型（`packages/shared`）。
4. 接口下线前确认调用方为零，并在文档记录下线日期。
5. OpenAPI 文档随代码生成，禁止手工维护与代码不一致的契约副本。

## 15. 禁止项

- 用 GET 做写操作；用 POST 做纯查询（已声明并标注的复杂筛选除外）
- 返回数据库实体，或返回 `password`、内部审计字段
- 两套成功约定混用（`200 + code` 与 `4xx + code` 并存）
- 前端传 `status` / `role` / `studentId` 直接落库
- 只靠前端隐藏按钮实现权限
- 把堆栈、SQL、内部类名返回给客户端
- 用业务异常抛 500；用 404 掩盖 403
- 在接口层"先查再改"实现配额扣减或状态流转（必须条件更新/原子操作）
- 语音接口把音频写磁盘或存入 OSS
- 用内存计数器承载验证码、登录锁定、面试配额等安全与配额边界

## 17. 接口评审清单

### 17.1 契约

- [ ] 路径符合第 1 章（前缀、分段、kebab-case、层级 ≤ 2）
- [ ] 方法语义正确，写操作用 POST/PUT/PATCH，查询用 GET
- [ ] 响应结构符合第 3 章，含 `code` / `message` / `data` / `traceId`
- [ ] 字段命名 lowerCamelCase，枚举为字符串常量
- [ ] 时间字段为 RFC 3339 UTC，`xxxAt` 后缀
- [ ] 未返回数据库实体与敏感字段
- [ ] OpenAPI 文档已生成且与实际一致

### 17.2 权限与安全

- [ ] C/B 前缀分离，Token 不可跨端使用
- [ ] 资源归属校验已实现（练习、作答、面试会话、报告）
- [ ] B 端接口声明所属模块，权限拦截器覆盖
- [ ] 入参校验与 PRD 规则一致（密码、验证码、轮次、配额）
- [ ] 日志与错误信息中无手机号明文、密码、Token

### 17.3 幂等与状态

- [ ] 写接口有幂等策略（第 9 章表）
- [ ] 状态流转只走专用接口，非法流转返回业务码
- [ ] 配额扣减/返还在事务内原子完成，重复请求不重复扣
- [ ] 过期判定用服务端时间

### 17.4 降级与异常

- [ ] 大模型超时/失败有降级路径，且用状态标记而非错误码
- [ ] ASR 失败可转文字，TTS 失败可回退文本
- [ ] 外部依赖失败返回 5xxxx 段错误码
- [ ] 无 5xx 泄露内部信息
